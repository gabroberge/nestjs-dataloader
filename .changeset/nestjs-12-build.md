Raise peer dependencies to **NestJS 12** (`@nestjs/common`, `@nestjs/core`) and **`@nestjs/graphql` 14**. Applications still on NestJS 11 or `@nestjs/graphql` 13 must upgrade before installing this release.

The package build was also modernized: the library now ships from a workspace package built with **tsdown** instead of tsup.
